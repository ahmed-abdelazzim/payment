# Product Roadmap: Sarraf Ops

## Version 1.0 (MVP) — Current Target
- [x] High-fidelity React 19 operational dashboard and mobile ledger views matching mockups.
- [x] Multi-tenant data isolation and organization model.
- [x] Ingestion security architecture with HMAC-SHA256 and replay defense.
- [x] Section 4A: Multi-wallet management, safe switching, and CBE regulatory limit alerts (80%/90%).
- [x] Section 4B: Cross-platform adapter matrix (MacroDroid, Dedicated Android, iOS Shortcuts, Huawei EMUI).
- [x] Section 12A: Out-of-order balance reconciliation, anchor checkpoints, and fake-message quarantine.
- [x] Operator Review Queue for ambiguous or unverified USSD/SMS items.
- [x] Bilingual English & Arabic interface with RTL/LTR direction parity.

## Version 1.5 — Near-Term Enhancements
- Automated outbound customer webhooks with HMAC signatures and exponential retry queue.
- Tenant-scoped Telegram bot integrations.
- Google Sheets export / sync integration.
- Native Android foreground service agent APK.

## Version 2.0 — Long-Term Enterprise
- Automated dynamic checkout routing across warm wallet pools based on real-time balance capacity.
- Central Bank of Egypt commercial open-banking API integration.
- Automated carrier USSD daemon on rooted/modem hardware for autonomous balance verification.
