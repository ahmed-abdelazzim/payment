بوابة دفع صرّاف الإلكترونية لربط محافظ فودافون كاش، إنستاباي، أورانج كاش، وإي آند كاش مع المتاجر الإلكترونية مع تأكيد فوري آلي.

== Description ==
صرّاف أوبس تتيح لك قبول مدفوعات فودافون كاش وإنستاباي مباشرة من عملائك دون وسيط بنكي أو استقطاعات، مع تأكيد آلي فوري لحالة الطلب.

== Installation ==
1. ارفع ملف الإضافة المضغوط عبر ووردبريس > إضافات > رفع إضافة (Upload Plugin).
2. فعّل الإضافة.
3. توجه إلى ووكومرس > الإعدادات > المدفوعات > صرّاف.
4. أدخل عنوان الخادم ومفاتيح الربط العامة والسرية.
